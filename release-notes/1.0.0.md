The first release of DictateMute.

DictateMute mutes you in Discord while you dictate to Claude Code, and unmutes you when you stop.

## What's in it

- Mutes Discord as soon as Claude Code starts listening to your microphone, and unmutes when it stops.
- Only undoes a mute it made. If you were already muted, you stay muted.
- Unmutes you if you quit in the middle of dictating.
- Works when Discord is full screen or on another desktop.
- Menu bar window with an on and off switch, live status, Launch at Login, and automatic updates.
- Works with VoiceOver and the keyboard.

## Install

Download DictateMute.zip below, unzip it, move DictateMute to Applications, and open it. Turn on DictateMute in System Settings, Privacy and Security, Accessibility when asked.

Requires macOS 14.2 or later, Claude Code with voice dictation, and the Discord desktop app with its menu bar icon on.
